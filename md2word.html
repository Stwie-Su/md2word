md2word

把大模型输出的 Markdown 转成 Word（.docx）· 纯浏览器本地运行，文件不外传 公式引擎：加载中…

0 字符

请用标准 Markdown 输出：行内公式用 $...$，独立公式用 $$...$$，表格用 Markdown 管道语法；公式用 LaTeX，禁止 \(...\) 和 \[...\]；表格前后各空一行。

.docx

支持元素
  • 标题（H1–H6，黑体加粗）
  • 加粗 / 斜体 / 行内代码（Consolas）
  • 有序 / 无序列表（含嵌套）
  • 代码块（灰底等宽字体）
  • 表格（可选普通表格 / 三线表）
  • 引用块 / 分割线 / 超链接
  • 数学公式：$…$、$$…$$、\(…\)、\[…\] → Word 原生可编辑公式（OMML）
